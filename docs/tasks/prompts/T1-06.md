## 1. Làm

1. **Package** (ghim phiên bản stable mới nhất): `zod`, `resend`, React Email (gói components + render theo docs hiện tại). Turnstile không cần package (script + `fetch` siteverify).
2. **Schema `leads`** (một migration `pnpm migrate:create leads_forms`):
   - `consentAt` (date, chỉ đọc trong admin).
   - `brief` group, chỉ hiện khi `need = business`: `company`, `teamSize`, `targetBehaviors`, `timeline`.
   - `service` (relation `services`, tùy chọn) cho form coaching.
   - Collection ẩn `rateLimitHits` { `key` (đã băm), `createdAt` } – không ai đọc qua API (`access` = `nobody`), không hiện trong admin.
3. **`src/lib/forms/`** (logic phía server, có `import 'server-only'` ở file `*.server.ts`):
   - Schema Zod cho 3 form; thông báo lỗi **tiếng Việt** dễ hiểu (lấy từ `vi.ts`).
   - Honeypot: có giá trị → trả về như thành công nhưng **không lưu, không gửi email**.
   - Rate limit lưu Postgres qua `rateLimitHits`: khóa = SHA-256(IP + `PAYLOAD_SECRET`) và SHA-256(email + `PAYLOAD_SECRET`) theo từng form; mặc định 5 lần / 10 phút; vượt → lỗi tiếng Việt "Bạn gửi hơi nhiều…". Không lưu IP gốc (NĐ 13). Dọn bản ghi cũ hơn 1 ngày khi ghi.
   - Turnstile: verify phía server; **tắt** khi thiếu `TURNSTILE_SECRET_KEY` và không phải production; production thiếu khóa → từ chối form và log lỗi cấu hình.
   - Hàm lõi nhận `(input, ctx: { ip, page, utm })` để test được không cần request thật. Server Actions mỏng gọi hàm lõi, lấy IP từ `headers()`.
4. **3 hàm**: `submitLead` (need, interestTags, consent bắt buộc → `consentAt = now`), `submitCoachingForm` (service + lời nhắn, `need = personal`, tag `coaching`), `submitB2BBrief` (`need = business` + `brief`). Lead tạo bằng Local API với `overrideAccess: true` **sau khi** validate (đúng comment REVIEW-REQUIRED trong `Leads.ts`); `source.form`, `source.page`, `source.utm` từ ctx.
5. **Email** `src/lib/email/` + template trong `src/emails/`:
   - Interface `EmailSender`; `ResendSender` khi có `RESEND_API_KEY`; không có khóa → `ConsoleSender` chỉ log tiêu đề + người nhận (không log nội dung form).
   - Sender lấy từ env `EMAIL_FROM` (mặc định `TRAM DUNG CAM XUC <no-reply@tramdungcamxuc.com>`).
   - Template: xác nhận cho khách (lead, coaching, B2B) và thông báo cho Hana (gửi tới email liên hệ trong `siteSettings`; trống → bỏ qua và log cảnh báo). Brand màu/font theo token, tiếng Việt có dấu.
   - Email lỗi **không** làm form thất bại: lead vẫn lưu, log lỗi.
6. **Admin `leads`**: bộ lọc theo `followUpStatus`, `source.form`, `need` (dùng tính năng có sẵn của Payload trước); nút **Xuất CSV** trên trang danh sách → route `src/app/(payload)/api/leads/export/route.ts` hoặc custom endpoint Payload: xác thực user admin (owner/editor) từ cookie, áp đúng bộ lọc đang chọn nếu làm được, CSV có **UTF-8 BOM**, chống CSV injection (ô bắt đầu bằng `= + - @` thêm `'`). `// REVIEW-REQUIRED:` ở chỗ kiểm quyền.
7. `.env.example`: thêm `RESEND_API_KEY`, `EMAIL_FROM`, `TURNSTILE_SECRET_KEY`, `NEXT_PUBLIC_TURNSTILE_SITE_KEY` (giá trị trống, có comment). Anh Nhân sẽ cấu hình khóa thật trên server demo.
8. Test (vitest, DB thật như các test hiện có, tự dọn dữ liệu):
   - Zod: thiếu consent / email sai → lỗi tiếng Việt.
   - Honeypot → không tạo lead.
   - Lần thứ 6 trong 10 phút → bị chặn; DB không có IP gốc.
   - `submitB2BBrief` hợp lệ → lead có `need = business`, `brief`, `consentAt`; email sender giả nhận 2 email (khách + Hana).
   - Sender ném lỗi → lead vẫn được tạo.
   - CSV: có BOM, tiếng Việt đúng, ô `=SUM(1)` bị vô hiệu; user chưa đăng nhập → 401/403.
   - E2E gửi form B2B **chưa viết** ở task này (chưa có khối form – T1-03 viết).
9. Quyết định (giới hạn rate limit, cách xuất CSV, cấu trúc email) ghi vào **`docs/decisions/T1-06.md`**.

**Không làm**: khối form trong Puck (T1-03, máy Local), giao tài nguyên (T1-07), thanh toán (T1-12), sửa `LeadForm` giao diện.
**Ranh giới file**: `package.json`, `pnpm-lock.yaml`, `src/collections/Leads.ts`, `src/collections/RateLimitHits.ts`, `src/payload.config.ts` (đăng ký collection), `src/migrations/*`, `src/payload-types.ts`, `src/lib/forms/**`, `src/lib/email/**`, `src/emails/**`, `src/app/(payload)/api/leads/**` hoặc endpoint tương đương, `src/components/admin/**` (nút CSV), `src/app/(payload)/admin/importMap.js` (tự sinh), `src/lib/i18n/vi.ts` (khối `forms`), `.env.example`, `tests/unit/forms*.test.ts`, `tests/unit/leads-export*.test.ts`, `docs/decisions/T1-06.md`, `docs/BACKLOG.md`.
