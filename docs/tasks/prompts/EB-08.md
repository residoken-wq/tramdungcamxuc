# EB-08 – Mẫu khối / mẫu trang + Lịch sử phiên bản trong builder (giao: Claude Code, **Laptop**)

Spec: `docs/plan/BUILDER_ELEMENTOR.md` (mục 4 task EB-08). Quyết định: `docs/decisions/EB-03.md`, `docs/decisions/EB-07.md` (clipboard, `prepareForPaste`, `insert` + `replace`). Review gần nhất: `docs/tasks/reviews/EB-07.md` (đọc kỹ B1–B7). AGENTS §5B (mẫu trang, lịch sử phiên bản), §7, §11. Ước lượng: 6 h. **Có migration** (collection mới).

**Bối cảnh:**

- Đã có: nút **"Dùng mẫu…"** (`TemplateModal` trong `PuckEditorClient.tsx`) chọn trong các mẫu trang viết bằng code (`src/puck/templates/*.ts`); nút **"Lịch sử"** liệt kê 25 phiên bản (`getVersionsAction`) và khôi phục (`restoreVersionAction`, `src/puck/actions.ts`); menu chuột phải + clipboard + `prepareForPaste` (EB-07).
- Elementor cho người dùng **tự lưu** một section / cả trang thành mẫu rồi chèn lại ở trang khác. Task này làm việc đó, và làm cho bảng Lịch sử dùng được với Hana.

**Không làm:** CSS tuỳ chỉnh (EB-09), header / footer (EB-10), ảnh chụp thu nhỏ của mẫu (BACKLOG), chia sẻ mẫu giữa các site / bản cài khác.

**Quyết định Planning (không hỏi lại):**

1. **Collection mới `blockTemplates`** (nhãn "Mẫu đã lưu"): `name` (bắt buộc, ≤ 80 ký tự), `kind` (`section` | `page`), `puckData` (JSON: `section` = một khối Puck kèm khối con; `page` = `{ content, root }`), `description?`, `createdBy` (user, tự điền, chỉ đọc). Có `createdAt` / `updatedAt`. Không có `status`, không versions.
2. **Quyền:** chỉ user admin đã đăng nhập (`owner`, `editor`) đọc / tạo / sửa; xoá: `owner`, hoặc `editor` xoá mẫu do chính mình tạo. **Không** đọc công khai (public `read` = false). `// REVIEW-REQUIRED:` ở access.
3. **Lưu thành mẫu:**
   - **Khối / section:** thêm mục **"Lưu thành mẫu"** vào menu chuột phải (EB-07) → hộp thoại nhập tên (+ mô tả) → lưu `kind: section`.
   - **Cả trang:** nút **"Lưu trang thành mẫu"** cạnh "Dùng mẫu…" → lưu `kind: page` từ dữ liệu đang mở (kể cả chưa lưu nháp).
   - Lưu qua **server action** (`src/puck/actions.ts` hoặc file mới cạnh đó) kiểm đăng nhập + quyền phía server; kiểm `puckData` phía server bằng cùng luật với dán (loại khối có trong config, ≤ 200 KB, ≤ 200 khối). Không tin dữ liệu từ trình duyệt.
4. **Chèn mẫu:**
   - **Section:** tab thứ ba **"Mẫu"** ở cột trái (cạnh "Khối" / "Cấu trúc"): danh sách mẫu section (tên, mô tả, ngày, người tạo, ô tìm không dấu); mỗi mẫu có nút **"Chèn"** (chèn sau khối đang chọn, không chọn khối nào thì chèn cuối trang) và **"Xoá"** (có hỏi lại, theo quyền). Chèn dùng `prepareForPaste` (id mới mọi tầng, kiểm vùng đích) + action `insert` + `replace` của Puck – **không** tự vá `data` (lỗi B1 của EB-07).
   - **Trang:** hộp thoại "Dùng mẫu…" có 2 nhóm: **"Mẫu có sẵn"** (code, như cũ) và **"Mẫu đã lưu"** (`kind: page`). Áp mẫu trang thay toàn bộ nội dung như mẫu code hiện làm (có hỏi lại khi trang đang có nội dung), id mới mọi tầng.
5. **Lịch sử phiên bản** (bảng "Lịch sử" đang có):
   - Mỗi dòng: thời gian (giờ Việt Nam, dạng "02/11/2026 14:05"), người lưu, nhãn **"Đã xuất bản"** / **"Bản nháp"** / **"Tự lưu"** (phân biệt từ dữ liệu version của Payload: `_status`, `autosave`).
   - **"Xem"**: nạp phiên bản vào editor để xem, **chưa** ghi gì; thanh báo trên canvas "Đang xem phiên bản 02/11 14:05 – Khôi phục / Thoát". **"Khôi phục"** mới ghi (như `restoreVersionAction` hiện có), có hỏi lại. Thoát thì trở về dữ liệu đang sửa trước đó (không mất thay đổi chưa lưu).
   - Bỏ `alert()`; lỗi / thành công dùng thông báo `role="status"` sẵn có.
   - Danh sách có nút "Xem thêm" (phân trang 25).
