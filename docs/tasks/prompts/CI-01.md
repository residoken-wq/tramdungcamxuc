## 6. Kiểm toàn bộ

Lỗi trên chỉ là những cái CI thấy trước khi dừng: CI dừng sớm sau 3 lỗi mỗi shard, còn test "did not run".

1. Chạy **toàn bộ** e2e trên DB e2e trống đã migrate, cả 2 project:

   ```bash
   pnpm test:e2e --project=desktop-1440
   ```

   ```bash
   pnpm test:e2e --project=mobile-375
   ```

   - Dev server cho e2e cần `E2E_TEST_HOOKS=1` và khoá Turnstile test như `.github/workflows/ci.yml`.
   - Có mạng ra Cloudflare thì bật Turnstile; không có thì ghi rõ test nào chưa kiểm được.
   - Lệnh quá 10 phút: chạy theo shard (`--shard=1/4` …), push sau mỗi phần sửa.
2. Sửa hết lỗi thấy được theo nguyên tắc ở trên.
3. `pnpm check:fast --affected` xanh.
4. Push nhánh. Mở **draft PR** vào `main` để CI chạy đủ 5 shard. Gửi link run.
   - Đỏ → sửa tiếp;
   - xanh → báo.
