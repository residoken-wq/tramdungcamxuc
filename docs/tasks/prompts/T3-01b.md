Làm trên **cùng nhánh** `task/T3-01-eq-schema` (chưa merge). Ước lượng: 3–4 h.

**Bối cảnh (anh Nhân chốt 15/10, sau khi có file bộ thẻ in của Hana):** mỗi thẻ thật gồm

- **Mặt trước**: một câu thông điệp + **một từ khóa tiếng Anh** (Abundance, Belonging, … Zero – đủ 26 chữ cái A → Z).
- **Mặt sau**: đúng **3 câu hỏi có nhãn cố định**: **Gợi nhớ**, **Gói ghém**, **Ghi nhận**.
- **Không có** câu chuyện, hành động nhỏ, từ khóa tiếng Việt, nhãn cảm xúc.

Chốt:

1. 3 câu hỏi lưu thành **3 ô cố định theo nhãn**, không phải danh sách 1–3 câu.
2. Câu chuyện, hành động nhỏ, từ khóa tiếng Việt: **không bắt buộc** (có thì hiện thêm, Hana bổ sung sau được).
3. **Bỏ chọn thẻ theo cảm xúc** (Q18 đổi): rút ngẫu nhiên + chọn theo từ khóa A–Z. `emotionTags` giữ là trường không bắt buộc, không dùng để lọc.
4. Mã thẻ `TDCX-01` … `TDCX-26` theo A → Z; `qrSlug` = từ khóa viết thường (`abundance` … `zero`).
5. **Repo công khai** (`docs/DECISIONS.md` mục 10/10): nội dung 26 thẻ **không** commit vào repo. Lệnh nhập đọc một file JSON **ngoài repo**; Planning / anh Nhân giữ file và chạy trên server.

## 1. Làm (mỗi mục 1 commit)

1. **Schema `eqCards`** (sửa migration `eq_cards_q17`, `down` trả về dạng cũ):
   - **Bỏ** mảng `reflectionPrompts` (và hook `ensureSampleReflectionPrompts`). Thêm 3 ô textarea, bắt buộc khi xuất bản:
     - `promptRecall` – nhãn "Gợi nhớ"
     - `promptPack` – nhãn "Gói ghém"
     - `promptAcknowledge` – nhãn "Ghi nhận"
       Gom 3 ô trong một nhóm giao diện "Mặt sau – 3 câu hỏi" (`type: 'row'` hoặc `collapsible`, **không** đổi tên cột DB).
   - Migration chuyển dữ liệu: giá trị `reflectionPrompt` cũ (nếu có) → `promptRecall`; `promptPack`, `promptAcknowledge` để rỗng.
   - `keywordEn` **bắt buộc** (nhãn "Từ khóa (mặt trước)", tối đa 40 ký tự). `message` bắt buộc (nhãn "Thông điệp (mặt trước)").
   - `keywordVi`, `story`, `smallAction`, `emotionTags`: không bắt buộc, mô tả admin ghi "Không bắt buộc – bộ thẻ in hiện không có".
   - Cột mặc định: `code`, `keywordEn`, `qrSlug`, `printedAt`, `_status`. `useAsTitle` giữ `code`.
2. **Lệnh nhập** `seed/import-eq.ts` + script `"import:eq": "cross-env NODE_OPTIONS=--no-deprecation payload run seed/import-eq.ts"`, logic ở `seed/import/eq-cards.ts` (export `importEqCards(payload, cards)` để test):
   - Đường dẫn file JSON lấy từ biến `EQ_CARDS_FILE` (truyền qua lệnh, **không** đọc / tạo `.env*`). Thiếu biến hoặc file nằm **trong** thư mục repo → dừng với thông báo tiếng Việt (chống commit nhầm nội dung).
   - Định dạng: mảng `{ code, keywordEn, qrSlug, order, message, promptRecall, promptPack, promptAcknowledge }`; kiểm bằng Zod (`qrSlug` theo regex của collection, `code` duy nhất, đủ 3 câu hỏi). Lỗi → in dòng lỗi, **không** ghi gì.
   - Tìm theo `code`: chưa có → tạo (`isSample: false`, `_status: 'published'`, `relatedProduct` = sản phẩm `EQ_BUDDY_PRODUCT_SLUG` nếu có). Đã có → cập nhật nội dung chữ, **không** đổi `qrSlug` của thẻ đã có `printedAt` (khác → báo, bỏ qua thẻ đó).
   - Sau khi nhập thành công: xóa thẻ MẪU (`isSample: true`). In bảng tạo / cập nhật / bỏ qua.
   - Chạy 2 lần không tạo trùng.
3. **Seed MẪU**: 3 thẻ `[MẪU]` theo schema mới (từ khóa, 3 câu hỏi).
