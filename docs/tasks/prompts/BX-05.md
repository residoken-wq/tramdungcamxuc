- Chỗ nào nghi ngờ thì hỏi Planning, **không** đoán.

### B. KHÔNG áp dụng: nhãn chức năng

Các nhãn này luôn giữ chữ mặc định, vì thiếu thì form / luồng hỏng hoặc khó dùng:

- nhãn ô nhập, placeholder, chữ nút gửi / nút mua / nút điều hướng;
- thông báo lỗi, thông báo đang tải;
- câu cảm ơn sau khi gửi form;
- nhãn trình đọc màn hình (`aria-label`);
- chữ pháp lý / chính sách;
- nhãn trong admin / builder.

Chữ ghi cứng trong `vi.ts` không đến từ CMS (nhãn UI cố định theo AGENTS mục 2.3) → **không đổi**.

## 1. Field + migration

- Mỗi phần thêm 1 checkbox `useDefaultCopy…` (tên rõ theo phần), đặt **đầu** nhóm / tab tương ứng, mặc định `false`.
- Global / collection: migration **chỉ thêm cột** `boolean DEFAULT false` (cả bảng `_v` nếu có versions), có `down()`. SQL thẳng, **không** gọi Local API (bài học PK-30). Không điền giá trị nào khác.
- Khối Puck: prop mới `useDefaultCopy`, `defaultProps: false`. Dữ liệu trang cũ không có prop → coi là `false` (đúng quyết định 3). Không cần Puck data migration vì không đổi / xoá prop cũ. Ghi rõ trong báo cáo.
- `defaultProps` chữ `[MẪU] …` khi kéo khối mới vẫn giữ: chữ mẫu đã nằm trong ô. Checkbox chỉ ảnh hưởng ô **trống**.

## 2. Render

- Một helper dùng chung, VD `pickCopy(value, fallback, useDefault)`:
  - chuỗi có chữ → `value`;
  - trống → `useDefault ? fallback : null`;
  - React element (sửa trực tiếp trên trang) → trả nguyên.
- **Phần mà mọi ô chữ đều trống** (và không có dữ liệu khác) → **ẩn cả phần**, không để khung / tiêu đề rỗng / khoảng trắng.
- Danh sách (module, khác biệt, 3 bước…) trống + checkbox tắt → ẩn phần; checkbox bật → danh sách mặc định.
- Không đổi logic giá, dùng thử, quyền, thanh toán.

## 3. Báo trước cho Hana trước khi deploy (bắt buộc)

Viết `scripts/report-empty-copy.ts`:

- **chỉ đọc**, không ghi gì;
- liệt kê mọi phần / khối trên DB đang **trống và đang hiện chữ mặc định** → sẽ **ẩn sau deploy BX-05**;
- in theo dạng: trang / global → phần → ô trống.

Ghi trong `docs/RUNBOOK.md` (mục deploy) cách anh IT chạy script này trên server **trước** khi deploy BX-05 (lệnh `docker compose … exec app …`), gửi danh sách cho Hana xem. Script không in dữ liệu cá nhân (chỉ tên trang / phần / ô).
