Quy tắc chung cho A1–A6:

### A1. Khối `Card` (thẻ con của `IconCardGrid` và thẻ đứng riêng)

Thêm các field:

- `cardBg`: 8 màu brand, mặc định theo kiểu thẻ hiện tại. Dùng cho thẻ vàng bơ / hồng phấn / bạc hà / tím sương / xanh thẫm (§4, §5, §8, §9, §19).
- `eyebrow`: nhãn nhỏ chữ hoa `bright-magenta` trên tiêu đề, kèm tuỳ chọn `eyebrowBar` (vạch dọc bên trái, §8, §19).
- `subtitle`: dòng đậm dưới tiêu đề (§11).
- `chip`: viên nhỏ, VD `Workshop 1` (§13, §15).
- `text` hỗ trợ **danh sách**: dòng bắt đầu bằng `- ` render thành `<ul>`, các dòng khác là đoạn. Render bằng React, không `dangerouslySetInnerHTML`.
- `items[]` `{ title, text }`: các cặp tiêu đề đậm / mô tả (§4, §16, §19). Thêm `itemsColumns: 1 | 2` (§15 bước 1: cột Nam tính / Nữ tính).
- `note { title, text }`: hộp "Mang về" nền nhạt cùng tông `cardBg`, hoặc tông chọn riêng nếu thẻ trắng (§11, §13, §15).
- Không có field nào: HTML như cũ.

### A2. `IconCardGrid`

- `columns` thêm giá trị `5` (§14, §16). Điện thoại 1 cột, máy tính bảng 2 cột.
- `connector: 'none' | 'arrow'`: mũi tên `bright-magenta` giữa các thẻ trên màn `lg` (§11, §13, §15). Ẩn trên điện thoại. Mũi tên là trang trí, `aria-hidden`.

### A3. Khối mới `MatrixTable` "Bảng lưới" (danh mục Nội dung)

Hai kiểu:

- **`grid`** (§18 Bản đồ 28 ngày):
  - `columns[] { label, color }`, `rows[] { label, cells[] { title, text } }`;
  - tiêu đề cột và ô cùng cột lấy nền theo `color`; nhãn hàng nền `lavender-mist`.
- **`list`** (§17 Reflection, §20 "Phase 1 mang sang"): mỗi dòng có nhãn bên trái + mô tả; tuỳ chọn vạch trái `accent-pink`, nền dòng theo màu.
- Tiêu đề section qua `TwoToneTitle` như khối khác, `bgColor`, `padding`.
- Nền `deep-navy`: chữ trắng, dòng nền trắng 8% (§17).
- Có thể thêm hàng chip phía trên (§17 "4 MỐC NHÌN LẠI" + 4 chip).
- Ngữ nghĩa: `grid` dùng `<table>` có `<th scope>`. Dưới `md` mỗi hàng thành một thẻ xếp chồng, có nhãn cột, không cuộn ngang ở 375.

### A4. Khối mới `LoopDiagram` "Vòng lặp" (danh mục Nội dung)

- `nodes[]`: 3–8 nút, VD `01 · Nhận diện vấn đề`. `centerText` (nghiêng, §7).
- Máy tính: nút xếp quanh một vòng tròn, mũi tên theo chiều kim đồng hồ. SVG nằm trong `src/components/brand/` hoặc tính toạ độ bằng CSS. Nút xen kẽ nền `lavender-mist` / viền `deep-navy`.
- Điện thoại: danh sách đánh số dọc, mũi tên xuống.
- Ngữ nghĩa: `<ol>` (thứ tự đọc 01→06), sơ đồ `aria-hidden`.
- Tôn trọng `prefers-reduced-motion` nếu có hiệu ứng.

### A5. `HeroImage`: danh sách dưới đoạn mô tả

- `listTitle`, VD `PHASE 1`.
- `listItems[] { text, muted }`: chấm đặc; `muted` = chấm rỗng + chữ mờ (§1).
- Áp cho cả 3 bố cục. Rỗng thì như cũ.

### A6. `Callout` strip: tông nền

- Thêm `stripTone`:
  - `soft-pink` (như hiện tại, mặc định);
  - `lavender-mist`;
  - `white` (viền mảnh);
  - `dashed` (viền đứt `accent-pink`, nền trong);
  - `deep-navy` (chữ trắng, tiêu đề `accent-pink`).
- Dùng ở §5, §6, §9, §13–§16.
