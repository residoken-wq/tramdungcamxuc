## 1. Làm

1. `pnpm add @payloadcms/live-preview-react@<cùng phiên bản payload> < /dev/null` – 1 commit riêng (chỉ `package.json` + `pnpm-lock.yaml`).
2. `admin.livePreview` cho `services`, `programs`, `posts` (gộp vào `admin` sau khi gọi `contentCollection()` trong từng file collection; không đổi chữ ký helper): URL trỏ tới trang chi tiết tương ứng (`/coaching/<slug>`, `/doanh-nghiep/<slug>`, `/blog/<slug>`), dựng bằng đường dẫn tương đối hoặc `getSiteUrl()` – không ghép tên miền cứng. 3 kích thước xem trước: 375, 768, 1440 (nhãn tiếng Việt).
3. Trang chi tiết nhận dữ liệu sống: tách phần thân thành client component dùng `useLivePreview` (chỉ bật khi đang ở trong iframe preview), server vẫn render bản `published` như hiện tại cho khách.
4. **Bản nháp chỉ cho người đăng nhập admin**: khi đang xem trước, trang được đọc bản nháp (`draft: true`) **chỉ khi** request có user admin hợp lệ (`payload.auth` + `isAdminUser`); khách thường không bao giờ thấy nháp, kể cả khi thêm query string. Không đặt cache công khai cho phản hồi có nháp. `// REVIEW-REQUIRED:` ở chỗ kiểm quyền.
5. Không nới security headers cho khách: iframe chỉ cùng origin (`frame-ancestors 'self'` đã có). Nếu phải đổi `security-headers.ts` → giải thích trong báo cáo.
6. **Test**:
   - Unit: hàm dựng URL preview cho 3 collection; khách không có user → không đọc nháp.
   - E2E (bạn **được chạy**, `PORT=3200`, `--project=desktop-1440`): `tests/e2e/live-preview.test.ts` – admin tạm tạo 1 service đã xuất bản (REST), mở trang sửa trong admin, bật Live Preview, gõ tiêu đề mới **chưa lưu** → iframe hiện tiêu đề mới; khách mở URL công khai vẫn thấy tiêu đề cũ. Locator theo vai trò / `frameLocator`, không `networkidle`. Dọn dữ liệu.
7. `docs/decisions/T1-10b.md` (cách bật preview, vì sao nháp không lộ); `docs/HUONG_DAN_CMS.md`: thêm mục ngắn "Xem trước khi sửa dịch vụ / chương trình / bài viết" (ảnh để chỗ trống `<!-- ẢNH 27: … -->`).

**Không làm**: Live Preview cho `pages` (Puck đã có xem trước), `products`, đổi schema, sửa giao diện trang chi tiết ngoài việc tách client component.
**Ranh giới file**: `package.json`, `pnpm-lock.yaml`, `src/collections/{Services,Programs,Posts}.ts` (chỉ `admin.livePreview`), `src/app/(site)/(shell)/{coaching,doanh-nghiep,blog}/[slug]/**`, `src/components/site/` (client component mới), `src/lib/detail-pages*.ts`, `src/lib/live-preview*.ts` (mới), `src/app/(payload)/admin/importMap.js` (nếu sinh lại), `src/lib/i18n/vi.ts`, `tests/unit/live-preview*.test.ts`, `tests/e2e/live-preview.test.ts`, `docs/decisions/T1-10b.md`, `docs/HUONG_DAN_CMS.md`.
