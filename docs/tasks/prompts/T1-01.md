```bash
GIT_TERMINAL_PROMPT=0 timeout 60 git fetch origin < /dev/null
git status --short          # có thay đổi chưa commit → DỪNG, báo lại
git switch -c task/T1-01-puck-blocks origin/main
pnpm install < /dev/null 2>&1 | tail -1 && pnpm migrate < /dev/null 2>&1 | tail -1
```

Đọc trước khi code: `docs/tasks/WORKFLOW.md`, AGENTS.md mục 5 và 5B, skill `tdcx-brand`, `docs/tasks/reviews/T0-09.md` (bài học spike Puck: không kéo Payload / `next/cache` vào `src/puck/config.tsx`). **Không có khóa**: task này không thêm package, không đổi schema. Cần một trong hai → DỪNG và hỏi.

## 1. Làm

1. 9 khối mới, mỗi khối một file `src/puck/blocks/<TenKhoi>.tsx` (config + kiểu props), import vào `src/puck/config.tsx`. Phần hiển thị dùng component trong `src/components/` (tạo mới ở `src/components/site/` nếu chưa có; `QuoteBlock` trong `ui/` đã có thì dùng lại):
   - **Mở đầu**: `HeroImage` (ảnh từ Thư viện media như `ImageText`, `alt` bắt buộc, tiêu đề 2 tầng, dòng cảm xúc, 1 nút).
   - **Nội dung**: `QuoteBlock`; `StatsBar` (2–4 ô số + nhãn, **Hana tự nhập**, `defaultProps` dùng `[MẪU]`, không điền số thật như "10+ năm"); `JourneySteps` (5 bước cố định Pause → Feel → Name → Choose → Practice, Hana sửa được mô tả từng bước); `FAQ` (accordion dùng `<details>/<summary>` hoặc nút có `aria-expanded`, điều khiển được bằng bàn phím); `VideoEmbed` (chỉ nhận URL YouTube/Vimeo công khai, dựng URL nhúng phía code bằng `youtube-nocookie.com` / `player.vimeo.com`, URL khác → hiện thông báo lỗi trong editor và không render iframe; iframe có `title`, `loading="lazy"`, tỉ lệ 16:9).
   - **Bố cục**: `Columns` (2 hoặc 3 cột; mỗi cột là một `slot`; không cho thả `Columns` vào trong `Columns`, không cho thả `HeroTwoEntries`/`HeroImage` vào cột; trên 375px xếp dọc); `Spacer` (chỉ 16/24/32/48/64); `Divider` (đường kẻ mảnh / nét trái tim dùng SVG có sẵn trong `src/components/brand/`).
2. Sidebar: thêm danh mục **Bố cục**; xếp khối đúng danh mục AGENTS.md 5B. Mọi nhãn khối/field tiếng Việt.
3. Giữ brand an toàn: màu chỉ qua dropdown dùng lại `SECTION_BG_COLOR_OPTIONS`; khoảng cách/cỡ chữ chỉ là mức S/M/L. **Không** có ô nhập màu, font, CSS, số pixel tự do. Màu nền tối (`deep-navy`) thì chữ phải đổi sang sáng (lỗi T0-09).
4. Mỗi khối có `version: 1` trong `defaultProps`. Không đổi props 5 khối cũ (nếu buộc phải đổi → viết migration trong `src/puck/migrations/`).
5. Sửa nhỏ còn tồn từ GĐ 0: tiêu đề `HeroTwoEntries` khi xuống 2 dòng thì dấu tiếng Việt dòng dưới chạm dòng trên → tăng `line-height` của Anton (vd. `leading-[1.15]`), không đổi props.
6. Test:
   - Unit (vitest): mỗi khối render bằng `renderToStaticMarkup` với `defaultProps` → snapshot; thêm test: `VideoEmbed` từ chối URL không phải YouTube/Vimeo; `Spacer` chỉ chấp nhận 5 mức; config không có field kiểu `text` nào tên chứa `color`/`font`/`css`.
   - **Viết** (không chạy) e2e `tests/e2e/puck-blocks.test.ts`: kéo `Columns` vào trang, thả `QuoteBlock` vào một cột, xuất bản, trang công khai hiện câu quote ở 375 và 1440. Theo mẫu `tests/e2e/puck-builder.spec.ts` hiện có.
7. Quyết định kỹ thuật (vd. slot hay DropZone, cách chặn lồng khối) ghi vào **`docs/decisions/T1-01.md`** (file mới), không sửa `docs/DECISIONS.md`.

**Không làm**: khối Bán hàng / Niềm tin / Chuyển đổi (T1-02, T1-03), mẫu trang / khóa khối / autosave (T1-04), Navbar/Footer (T1-05, máy Laptop).
**Ranh giới file**: `src/puck/**`, `src/components/site/` (chỉ file mới + `HeroTwoEntries.tsx`; **không** sửa `index.ts`, `Navbar.tsx`, `Footer.tsx` – vùng Laptop; import thẳng từ file), `src/components/ui/QuoteBlock.tsx` (chỉ khi cần thêm prop không phá chỗ dùng cũ), `src/lib/i18n/vi.ts` (chỉ khối `builder`), `tests/unit/puck*.test.tsx`, `tests/e2e/puck-blocks.test.ts`, `docs/decisions/T1-01.md`, `docs/BACKLOG.md`. Sửa file khác → DỪNG và hỏi.

## 2. Kiểm và nộp

Commit sau mỗi 2–3 khối, mở PR nháp ngay lần push đầu:

```bash
git add -A && git commit -m "feat(puck): add <khối> blocks (T1-01)"
GIT_TERMINAL_PROMPT=0 timeout 60 git push -u origin HEAD < /dev/null
GIT_TERMINAL_PROMPT=0 timeout 60 gh pr create --draft --base main --title "feat(puck): intro, content and layout blocks (T1-01)" --body "Máy Local. E2E: Planning chạy." < /dev/null
```

```bash
pnpm lint 2>&1 | tail -3 ; pnpm typecheck 2>&1 | tail -5 ; pnpm test < /dev/null 2>&1 | grep -E "FAIL|Error|Test Files|Tests " | head -10
git status --short   # phải sạch
GIT_TERMINAL_PROMPT=0 timeout 60 gh pr ready < /dev/null
```
