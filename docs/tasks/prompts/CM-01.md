## 1. Làm (mỗi mục 1 commit)

1. **Nhóm + thứ tự menu** đúng bảng mục 3: đặt `admin.group` cho **mọi** collection (kể cả collection tạo bằng `contentCollection` – thêm tham số / ghi đè sau khi tạo, không đổi slug), sắp lại mảng `collections` trong `src/payload.config.ts` theo thứ tự nhóm. Tên nhóm vào `vi.ts` (khối `cms.nav`).
2. **Ẩn mục kỹ thuật với `editor`**: nhóm "Hệ thống" dùng `admin.hidden: ({ user }) => user?.role !== 'owner'` (đúng chữ ký theo docs Payload). **Không** đổi `access` (quyền API giữ nguyên) – chỉ ẩn khỏi menu. `// REVIEW-REQUIRED:` ở helper.
3. **Mô tả + cột**: mỗi collection Hana dùng có `admin.description` 1 câu "dùng để làm gì", `defaultColumns` 3–5 cột có ích (vd Sản phẩm: tên, loại, trạng thái bán, giá, cập nhật), `listSearchableFields` hợp lý, `useAsTitle` có nghĩa (không để id).
4. **Logo + màu nhấn nhẹ cho admin** (`admin.components.graphics.Logo` / `Icon`, file CSS admin theo docs): logo từ `public/brand/`, màu nhấn `accent-pink` / `deep-navy`; **không** đổi bố cục Payload, tương phản AA. `admin.meta.titleSuffix` = " – Trạm Dừng Cảm Xúc".
5. **Test**: unit kiểm mọi collection có `admin.group` thuộc danh sách nhóm hợp lệ; hàm ẩn trả `true` cho editor, `false` cho owner ở nhóm Hệ thống; collection không thuộc Hệ thống không bị ẩn.
6. **Tài liệu**: `docs/HUONG_DAN_CMS.md` – đoạn "Menu bên trái" mới (bảng nhóm), `docs/decisions/CM-01.md`.

**Ranh giới file**: `src/payload.config.ts` (chỉ thứ tự + `admin`), `src/collections/**` (chỉ khóa `admin`), `src/fields/content.ts` (chỉ tham số nhóm của `contentCollection`), `src/components/admin/brand/**`, `src/app/(payload)/**` (CSS admin, importMap sinh lại), `src/lib/i18n/vi.ts` (khối `cms.nav`), `tests/unit/cms-nav*.test.ts`, `docs/HUONG_DAN_CMS.md`, `docs/decisions/CM-01.md`.
