## Vì sao

- Trang offer Habit Hack (`src/app/(site)/(shell)/habit/1-percent-better/page.tsx` → `src/components/habit/HabitOfferClient.tsx`) là trang code. Hana **chỉ sửa được** những gì đã nằm trong sản phẩm `habit-tracker-so`:
  - giá, dùng thử;
  - "Bao gồm" (`includes`);
  - FAQ.
- Phần chữ còn lại ghi cứng trong `vi.ts` (`vi.habit.offer`), Hana không sửa được:
  - nhãn, tiêu đề 2 dòng, dòng cảm xúc;
  - "Lộ trình 4 Module";
  - "Tại sao Habit Tracker số khác biệt?";
  - khối kêu gọi cuối trang.
- Anh Nhân chốt 08/11: thêm field vào **sản phẩm**, sửa bằng **form như giá** (AGENTS.md mục 5B: trang bán hàng sửa bằng form Payload, không kéo thả).

## 1. Làm

### 1.1 Field mới trong collection `products` (`src/collections/Products.ts`)

Thêm một tab mới **"Trang giới thiệu"**, chỉ hiện với `type = digital_tool` (dùng `showFor`). Mọi field **không bắt buộc**.

| Field                  | Kiểu                                                    | Nhãn (tiếng Việt, trong `vi.ts`)                                     |
| ---------------------- | ------------------------------------------------------- | -------------------------------------------------------------------- |
| `offerSeriesLabel`     | text                                                    | Nhãn nhỏ trên tiêu đề                                                |
| `offerTitleLine1`      | text                                                    | Tiêu đề dòng 1 (xanh thẫm)                                           |
| `offerTitleLine2`      | text                                                    | Tiêu đề dòng 2 (hồng sen)                                            |
| `offerEmotionLine`     | text                                                    | Dòng cảm xúc (chữ nghiêng)                                           |
| `curriculumHeading`    | text                                                    | Tiêu đề phần lộ trình                                                |
| `curriculumSubheading` | textarea                                                | Mô tả phần lộ trình                                                  |
| `curriculumModules`    | array { `title` text bắt buộc, `description` textarea } | Các module (tối đa 8)                                                |
| `featuresHeading`      | text                                                    | Tiêu đề phần "khác biệt"                                             |
| `featuresSubheading`   | textarea                                                | Mô tả phần "khác biệt"                                               |
| `featureItems`         | array { `title` text bắt buộc, `description` textarea } | Các điểm khác biệt (tối đa 6)                                        |

| `bottomDescription`    | textarea                                                | Mô tả kêu gọi cuối trang                                             |

- Mỗi field có `admin.description` ngắn, nói rõ: **"Để trống = dùng chữ mặc định"**.
- Không đổi field cũ, không đổi tên. `includes`, `faq`, giá: giữ nguyên.

### 1.2 Migration (`pnpm payload migrate:create pk30_habit_offer_fields`)

- Tạo cột / bảng cho các field mới. Chỉ thêm, không xoá.
- **Điền sẵn chữ hiện tại** cho sản phẩm slug `habit-tracker-so`, **chỉ khi field đang trống**. Chữ lấy đúng từ `vi.habit.offer` hiện nay:
  - tiêu đề, module, điểm khác biệt…;
  - `bottomTitle` = `Bắt đầu hành trình {ngay} ngày của bạn`.
- Vì vậy Hana mở form là thấy chữ đang hiện trên web để sửa, không phải ô trống.
- Làm cho **cả bản đã xuất bản lẫn bản nháp** (Products có versions). Kiểm `_products_v` và `_status`.
  - Cách an toàn: dùng Payload Local API trong `up()` (`payload.update` với `draft: false`) thay vì SQL tay. Nếu không được, ghi lý do trong báo cáo.
- `down()`: xoá cột / bảng mới.
- **Không** đụng sản phẩm khác. Không có sản phẩm `habit-tracker-so` thì bỏ qua, không lỗi.
- Đánh dấu `// REVIEW-REQUIRED:` ở phần ghi dữ liệu trong migration.

### 1.3 Trang offer (`HabitOfferClient.tsx`, `src/lib/habit.server.ts`)

- `getHabitProduct` trả thêm các field mới (chỉ field công khai; vẫn **không** trả `files`).
- Mỗi chỗ chữ: dùng field nếu có chữ, rỗng thì rơi về `vi.habit.offer` như hiện nay. Cụ thể:
  - `curriculumModules` rỗng → 4 module trong `vi.ts`;
  - `featureItems` rỗng → 3 mục trong `vi.ts`;
  - `bottomTitle`: thay `{ngay}` bằng `journeyDays`;
  - `bottomDescription` rỗng → `vi.habit.offer.bottomDesc(...)`.
- Ô số liệu "Module lộ trình": hiện **số module thật** (`curriculumModules.length`, hoặc 4 khi dùng mặc định), thay chữ cố định `modulesValue: '4'`.
- Live Preview: trang đã có `RefreshOnSave` + đọc bản nháp cho admin. Sửa field trong form → bấm Lưu → trang xem trước cập nhật. Kiểm lại.
- Không đổi bố cục, màu, font. Không có dữ liệu mới thì trang ra **y như cũ**.

### 1.4 Hướng dẫn CMS (`docs/HUONG_DAN_CMS.md`, sửa bằng tay)

Thêm mục **"Sửa trang Habit Hack (/habit/1-percent-better)"**:

- **Admin → Sản phẩm → Habit Tracker số → tab "Trang giới thiệu"**. Liệt kê từng ô ứng với phần nào trên trang.
- Giá, dùng thử, "Bao gồm", FAQ: vẫn ở các tab cũ.
- Số video / kỹ thuật: tự đếm từ **Bài học** / **Kỹ thuật**. Số ngày: **Cài đặt site**.
- Bấm **Lưu** để xem trước, **Xuất bản** để lên web.
