## 1. Quy tắc dữ liệu (bắt buộc – tiêu chí nghiệm thu)

`puckData` lưu trong DB **chỉ chứa ID sản phẩm và tùy chọn hiển thị**, không bao giờ chứa tên, giá, ảnh, cấu phần. Khác với `ImageText` (lưu `imageUrl` qua `resolveData`) – **không** dùng `resolveData` để chép dữ liệu sản phẩm vào props.

- **Trang công khai**: `resolveServerData` (dùng `walkPuckItems`) gom mọi ID sản phẩm trong trang, gọi Payload **một lần** (`where: id in […]`, chỉ `_status = published`, `depth: 1` để có ảnh bìa), rồi gắn vào props một khóa tạm `_resolved` chỉ tồn tại lúc render.
- **Editor**: component render thấy chưa có `_resolved` → dùng một component client (`'use client'`) tự `fetch('/api/products?where[id][in]=…&depth=1')` để xem trước. Không ghi kết quả ngược vào props.
- Giá hiển thị luôn qua `getEffectivePrice(product, now)`; nút qua `resolveProductCta(product, now)` (T1-08). Sản phẩm `hidden` hoặc chưa xuất bản → bỏ qua, không lỗi.
- Không import Payload / `server-only` vào `src/puck/config.tsx` hay file block (bài học T0-09).
