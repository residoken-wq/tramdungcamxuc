# T0-12 – Bật tiếng Việt cho trang quản trị Payload (giao: Antigravity, máy Local hoặc máy bất kỳ)

Lý do: hướng dẫn CMS (`docs/HUONG_DAN_CMS.md`) gọi nút bằng tiếng Việt (**Tạo mới**, **Lưu**, **Lưu bản nháp**, **Xuất bản**, **Đăng nhập**, **Mật khẩu mới**, **Đổi mật khẩu**) nhưng admin hiện chạy tiếng Anh. Payload 3.90 có sẵn bản dịch `vi` với đúng các chữ đó. Đây là điều kiện để Hana làm bài thử cổng GĐ 0.

## 0. Chuẩn bị

```bash
GIT_TERMINAL_PROMPT=0 timeout 60 git fetch origin < /dev/null
git status --short          # có thay đổi chưa commit → DỪNG, báo lại
git switch -c task/T0-12-admin-vi origin/main
pnpm install < /dev/null 2>&1 | tail -1 && pnpm migrate < /dev/null 2>&1 | tail -1
```

**Khóa Package**: task này thêm 1 dependency – không task nào khác được thêm package cùng lúc (WORKFLOW.md luật 5).

## 1. Làm

1. Đọc docs Payload 3.90 "I18n" (cấu hình `i18n` trong `buildConfig`, `supportedLanguages`, `fallbackLanguage`) – đọc trong `node_modules/payload` / `node_modules/@payloadcms/translations` hoặc payloadcms.com/docs, không dựa trí nhớ.
2. Thêm dependency `@payloadcms/translations` **đúng phiên bản 3.90.2** (ghim cứng, cùng bản với các gói `@payloadcms/*` khác).
3. `src/payload.config.ts`: bật `i18n` với **chỉ tiếng Việt** (`supportedLanguages: { vi }`, `fallbackLanguage: 'vi'`) – Hana không cần chuyển ngôn ngữ. Comment tiếng Anh giải thích vì sao.
4. `tests/e2e/content-admin.test.ts` dòng có `aria-label="Open Menu"`: đổi sang selector **không phụ thuộc ngôn ngữ** (vd. `button.nav-toggler:visible`). Tìm thêm chỗ test nào dựa vào chữ tiếng Anh của admin (`git grep -nE "Open Menu|Close Menu|Create New|Save Draft|Publish" tests`) và sửa tương tự.
5. Unit test mới (vd. `tests/unit/admin-i18n.test.ts`): import config, kiểm `i18n.fallbackLanguage === 'vi'` và `supportedLanguages` chỉ có `vi`.
6. `docs/BACKLOG.md`: đánh dấu mục "Admin Payload tiếng Việt" → "→ T0-12".

**Không làm**: dịch nhãn collection/field (đã tiếng Việt sẵn), sửa giao diện site, sửa `HUONG_DAN_CMS.md`.
**Ranh giới file**: `package.json`, `pnpm-lock.yaml`, `src/payload.config.ts`, `src/app/(payload)/admin/importMap.js` (nếu tự sinh lại), `tests/e2e/*`, `tests/unit/admin-i18n.test.ts`, `docs/BACKLOG.md`. Sửa file khác → DỪNG và hỏi.

## 2. Kiểm và nộp

```bash
pnpm lint 2>&1 | tail -3 ; pnpm typecheck 2>&1 | tail -5 ; pnpm test < /dev/null 2>&1 | grep -E "FAIL|Error|Test Files|Tests " | head -10
git add -A && git commit -m "feat(admin): Vietnamese admin UI via Payload i18n (T0-12)"
GIT_TERMINAL_PROMPT=0 timeout 60 git push -u origin HEAD < /dev/null
GIT_TERMINAL_PROMPT=0 timeout 60 gh pr create --base main --title "feat(admin): Vietnamese admin UI (T0-12)" --body "Bật i18n vi cho admin Payload để khớp HUONG_DAN_CMS. E2E: Planning chạy." < /dev/null
```

**KHÔNG** chạy e2e / Playwright / `pnpm dev` foreground (Planning chạy e2e và chụp ảnh admin khi nghiệm thu). **KHÔNG** `gh pr merge`. Trả lời ngắn: link PR + selector e2e đã đổi.
