2. **`admin.condition` theo `type`** đúng bảng mục 5 kế hoạch (helper `showFor(['digital_tool', …])` trong `src/lib/cms/product-form.ts`, có unit test). Trường bị ẩn **giữ nguyên dữ liệu cũ** (không xóa giá trị khi đổi loại).

4. **Cảnh báo khi đang bán mà thiếu dữ liệu**: `saleStatus = on_sale` mà thiếu giá (trừ miễn phí / Shopee), thiếu ảnh bìa hoặc thiếu slug → `validate` trả lỗi tiếng Việt rõ ràng (chặn lưu bản **xuất bản**, cho lưu **nháp** – theo docs Payload về validate với draft). `// REVIEW-REQUIRED:` vì ảnh hưởng luồng bán.
