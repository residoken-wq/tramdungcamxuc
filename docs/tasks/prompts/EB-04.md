## 1. Làm (mỗi mục 1 commit)

Code mới đặt trong `src/puck/style/` (thư mục mới), phần UI editor trong `src/puck/editor/`.

1. **Spike 30 phút → ghi quyết định trước khi code tiếp.** Chọn cách chia 3 tab với Puck 0.23 rồi ghi vào `docs/decisions/EB-04.md` mục 1. Ví dụ:
   - `overrides.fields` nhận danh sách field rồi lọc theo tab;
   - hoặc custom field `_style` tự vẽ tab Kiểu / Nâng cao, còn tab Nội dung hiện các field còn lại.

   Yêu cầu chung:
   - tab đang chọn giữ nguyên khi bấm sang khối khác;
   - bàn phím đi được (`role="tab"`, `aria-selected`).

2. **Dữ liệu và luật** `src/puck/style/style-schema.ts` (hàm thuần, dùng được ở client):
   - Kiểu `BlockStyle` (prop `_style`, mọi field tuỳ chọn):
     - **Kiểu:** `background` (token màu hoặc hex), `textColor`, `fontFamily`, `fontSize`, `fontWeight` (400 / 600 / 700), `lineHeight`, `textAlign`, `radius`, `borderWidth`, `borderColor`, `shadow` (`none` / `soft` / `strong`).
     - **Nâng cao:** `padding` / `margin` (4 cạnh), `hideOn` (`desktop` / `tablet` / `mobile`), `anchorId` (chữ thường, số, gạch nối; dùng làm `id` cho link `#neo`).
   - **Giá trị theo thiết bị** `Responsive<T> = { desktop?: T; tablet?: T; mobile?: T }` cho `padding`, `margin`, `fontSize`, `textAlign`. Thiếu thì kế thừa: điện thoại ← máy tính bảng ← máy tính (như Elementor).
     - Ngưỡng: điện thoại ≤ 767px, máy tính bảng 768–1023px, máy tính ≥ 1024px. Ghi vào decisions. Khớp với 3 khổ xem trước 375 / 768 / 1440.
   - **Khi khoá** (`lock.sizes = locked`): cách lề / cỡ chữ / bo góc chỉ nhận **mức có sẵn** (S / M / L… ánh xạ sang `spacing` / `radiusCard` / cỡ chữ đang dùng). Khi **mở**: số + đơn vị, có khoảng (ví dụ padding 0–200px, font 10–96px).
   - **Khi khoá** (`lock.colors = locked`): màu chỉ là **token** trong bảng màu `designSystem`. Khi **mở**: thêm hex tự do.
   - **Khi khoá** (`lock.fonts = locked`): không có `fontFamily` (dùng font vai trò). Khi **mở**: chọn trong `DESIGN_FONT_OPTIONS`.
   - `sanitizeBlockStyle(raw, designSystem)`: bỏ mọi giá trị sai hoặc bị khoá. Test kỹ (mục 7).
3. **Sinh CSS** `src/puck/style/style-css.ts`:
   - `blockStyleCss(id, style, designSystem)`: trả CSS cho một khối, chọn bằng `[data-eb-id="<id>"]`, kèm `@media` theo 3 ngưỡng. Màu token → `rgb(var(--color-<token>-rgb))` để đổi bảng màu là đổi theo.
   - `collectPageStyles(data, designSystem)`: duyệt cả cây Puck, **kể cả khối trong slot / vùng thả**. Trả `{ css, fonts }` cho cả trang; `fonts` là các font đang dùng để tải Google Fonts.
4. **Render:**
   - Bọc **chỉ khi** khối có `_style` hợp lệ (sau `sanitize`): thêm `data-eb-id`, `id` = `anchorId` nếu có.
     - Tìm cách gắn thuộc tính vào phần tử gốc mà **không đổi bố cục**, ví dụ thẻ bọc `display: contents` khi chỉ có `hideOn` / `anchorId`.
     - Nếu cần thẻ bọc thật (padding, nền, viền) thì dùng `<div>` và ghi rõ trong decisions.
   - Trang công khai (`[...slug]`, trang chủ, các trang dùng `<Render>`): server gọi `collectPageStyles` → một `<style>` duy nhất cho cả trang + `<link>` font nếu cần (dùng lại cách của EB-02, không tải trùng font đã có).
   - Trong editor: CSS cập nhật ngay khi sửa, có trong iframe xem trước.
5. **Bảng sửa 3 tab** (`src/puck/editor/StylePanel*.tsx` + override):
   - **Nội dung:** field hiện có của khối, trừ các field định dạng.
   - **Kiểu:** field định dạng hiện có của khối (theo danh sách tên trong `src/puck/style/field-groups.ts`, ví dụ `size`, `color`, `align`, `bg`… đọc từ code thật), rồi các nhóm Nền / Chữ / Viền & bo góc / Bóng.
   - **Nâng cao:** Cách lề (padding / margin 4 cạnh, nút liên kết 4 cạnh), Ẩn trên thiết bị, ID neo.
   - **Biểu tượng thiết bị** cạnh mỗi field theo thiết bị: bấm thì đổi khổ xem trước của Puck (đồng bộ với thanh dưới của EB-03), field hiện giá trị của thiết bị đó, có dấu khi đang kế thừa.
   - Màu: ô mẫu các token trong bảng màu. Khi `colors = open` có thêm ô chọn màu tự do.
   - **Cảnh báo tương phản** (khi `lock.contrastCheck` bật): chữ / nền dưới 4.5:1 thì hiện dòng cảnh báo, không chặn.
   - Nút **"Đặt lại kiểu"** cho từng tab: xoá phần `_style` tương ứng.
   - Builder lấy `designSystem` ở server (`page.tsx`) rồi truyền vào editor. Editor **không** tự gọi API.
6. **Gắn `_style` cho mọi khối** trong `getPuckConfig` (hoặc hàm bọc riêng), **không sửa từng file khối**. Khối bị khoá theo `locks.ts` vẫn khoá như cũ.
7. **Test:**
   - Unit `tests/unit/puck-style-schema.test.ts`:
     - kế thừa thiết bị;
     - `sanitize` bỏ hex sai, đơn vị lạ, số ngoài khoảng, token không có, font ngoài danh sách;
     - khoá → bỏ giá trị tự do;
     - `anchorId` sai dạng → bỏ.
   - Unit `tests/unit/puck-style-css.test.ts`:
     - CSS đúng `@media` 3 ngưỡng;
     - token → biến CSS;
     - không có chuỗi lạ lọt vào CSS (thử `;}body{display:none` trong mọi field → không xuất hiện);
     - `collectPageStyles` duyệt cả slot lồng nhau;
     - trang không có `_style` → `css` rỗng.
   - Snapshot các khối hiện có **không đổi**. Thêm snapshot một khối có `_style`.
   - Component `tests/unit/puck-style-panel.test.tsx`:
     - 3 tab, `aria-selected`;
     - khoá → không có ô màu tự do / ô số;
     - mở → có;
     - cảnh báo tương phản.
   - E2E mới `tests/e2e/puck-style-panel.test.ts`, **tự đủ trên DB trống** (tự tạo trang thử, tự xoá):
     - thêm khối → tab Kiểu đổi nền sang token khác → tab Nâng cao đặt padding riêng cho điện thoại → xuất bản;

     - đặt "Ẩn trên điện thoại" → 375px không thấy, 1440px thấy.

8. **Tài liệu:**
   - `docs/decisions/EB-04.md`:
     - cách chia tab (spike);
