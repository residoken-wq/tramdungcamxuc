## 1. Làm

### 1.1 Điều kiện hiện thẻ (`resolve.server.ts`, cả `auto` và `manual`)

- Sản phẩm hiện khi đủ 3 điều kiện:
  - `_status = published`;
  - `saleStatus = free`;
  - **có `files` ≥ 1, hoặc có `externalUrl`** (hợp lệ theo `safeHref`).
- Thêm vào `_resolved.items` của mỗi thẻ:
  - `href`: có file → `/tai-nguyen/<slug>` (như cũ); không file mà có `externalUrl` → link đó;
  - `isExternal`: `true` khi link bắt đầu bằng `http`;
  - `ctaLabel`: `ctaLabel` của sản phẩm nếu có, không thì để trống (component tự dùng chữ mặc định).
- Sản phẩm vừa có file vừa có link: **ưu tiên file** (giữ luồng thu lead).
- Giữ `sort: 'order'`, tối đa 12.

### 1.2 Component (`src/components/site/LeadMagnetCarousel.tsx`)

- Cả kiểu List và Carousel:
  - nút dùng `item.href`;
  - nhãn nút = `item.ctaLabel` hoặc chữ mặc định trong `vi.ts`:
    - có file: "Nhận tài liệu" (đang ghi cứng trong JSX, chuyển vào `vi.ts`);
    - có link: "Dùng miễn phí".
- Link ngoài (`isExternal`): `target="_blank"`, `rel="noopener noreferrer"`, ghi sự kiện `external_clicked`.
- Link trong web: mở cùng tab.
- Không đổi màu / kiểu thẻ hiện có. Snapshot cũ phải giữ nguyên (thẻ có file ra HTML như trước, kể cả chữ "Nhận tài liệu →").

### 1.3 CMS (`src/collections/Products.ts`)

- `externalUrl` hiện thêm khi `saleStatus = free`, **bất kể loại sản phẩm**.
  - Thêm điều kiện cạnh `showFor`, VD hàm `showForTypesOrFree([...])` trong `src/lib/cms/product-form.ts`.
  - Áp cho cả group / collapsible bọc field nếu group đó cũng có `condition`.
- Chỉ đổi điều kiện hiển thị. **Không** đổi tên field, **không** đổi DB, **không** migration.
- Mô tả field (`vi.cms.productForm.descriptions.externalUrl`), thêm 1 câu: "Sản phẩm Miễn phí không có file: nhập link công cụ (VD `/habit/chan-doan`) để hiện trong khối Tài nguyên miễn phí."
- Đổi nhãn field chọn tay trong `LeadMagnetCarousel` thành: "(Miễn phí & có file hoặc có link)".
- `vi.sm05.carousel.emptyEditor`: "Chưa có tài nguyên miễn phí – tạo sản phẩm "Miễn phí" có file hoặc có link trong CMS".

### 1.4 Hướng dẫn CMS (`docs/HUONG_DAN_CMS.md`, mục khối `LeadMagnetCarousel`, sửa bằng tay)

- Thẻ hiện khi sản phẩm **Miễn phí + Đã xuất bản + (có file PDF hoặc có Liên kết của nút)**:
  - có file: khách để email nhận file;
  - chỉ có link: bấm đi thẳng tới công cụ.
- VD "Chẩn đoán điểm kẹt thói quen":
  - Liên kết của nút = `/habit/chan-doan`;
  - Nhãn nút = "Nhận công cụ miễn phí".
- Nhắc Hana: công cụ **bán sau dùng thử** (EQ Buddy số, Habit Tracker) để trạng thái **Đang mở bán** + số ngày dùng thử, **không** để "Miễn phí".
