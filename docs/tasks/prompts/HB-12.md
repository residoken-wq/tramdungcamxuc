## 1. Làm (mỗi mục 1 commit, push sau mỗi commit)

1. **Collection `habitReflections`** (`src/collections/HabitReflections.ts`, đăng ký trong `payload.config.ts`, slug ghi vào `docs/decisions/HB-12.md`):
   - Field: `customer` (gắn từ khách đăng nhập khi tạo, khách không đổi được), `plan` (relation `habitPlans`, bắt buộc), `stationIndex` (số, 0-based, bắt buộc), `answers[]` { `question` (text – **chụp lại** câu hỏi lúc trả lời, để Hana sửa câu hỏi sau này không làm lệch câu trả lời cũ), `answer` (textarea, ≤ 1000 ký tự) }, tối đa 10 dòng; khóa duy nhất `plan + stationIndex` (`uniqueKeyField` / `uniqueKeyHook`).
   - Quyền: collection `read / create / update` = `adminOrSelfCustomer()`, `delete` = `isOwner` (như `SavedCards`); `admin.hidden: isHiddenFromEditor`. Field `answers` `read / create / update` = `selfCustomerOnlyField`. Hook `beforeChange`: kế hoạch phải thuộc đúng khách (không thì lỗi tiếng Việt). Đánh `// REVIEW-REQUIRED:` ở quyền + hook.

Tạo mới hoặc cập nhật bản cũ (theo khóa `plan + stationIndex`). Trả `{ ok } | { error }` tiếng Việt.
