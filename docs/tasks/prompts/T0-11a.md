## 0. Chuẩn bị (chạy ở thư mục gốc repo của máy này)

```bash
GIT_TERMINAL_PROMPT=0 timeout 60 git fetch origin < /dev/null
git status --short                       # có thay đổi chưa commit → DỪNG, báo lại, không xóa
git switch -c task/T0-11a-estimates origin/main
```

Nếu nhánh `task/T0-11a-estimates` đã có trên GitHub (máy khác làm dở): `git switch task/T0-11a-estimates && git pull --ff-only` rồi làm tiếp.

1. **Tốc độ GĐ 0** rút từ dữ liệu: thời gian giao → merge mỗi task, số vòng sửa trung bình, 5 loại lỗi hay gặp nhất (vd. e2e viết mà không chạy, quên `'use client'`, hardcode nội dung, tương phản màu, kéo code server vào client, test đua migration).

3. **Đề xuất tách/gộp**: task nào quá lớn cho một lượt agent thì tách (bài học GĐ 0: lượt dài dễ treo, hết quota).
