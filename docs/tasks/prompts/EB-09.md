**Quyết định Planning (không hỏi lại):**

1. **Ai dùng được:** các field của task này chỉ **hiện** khi `designSystem.lock.customCss = open` **và** user đang đăng nhập là `owner`. Ẩn ở giao diện chưa đủ:
   - **Khi render** (trang công khai và canvas): `customCss` khoá thì **không** xuất CSS tuỳ chỉnh, widget HTML hiện khoảng trống (trang công khai) / dòng nhắc "Đang khoá" (editor).
   - **Khi lưu** (`saveDraftAction`, `publishPageAction`, lưu mẫu EB-08): user không phải `owner` mà dữ liệu gửi lên **thay đổi** bất kỳ `_style.customCss` hoặc nội dung widget HTML so với bản đang lưu → từ chối cả lần lưu với thông báo rõ ("Chỉ chủ site được sửa CSS / HTML tuỳ chỉnh"). Editor vẫn sửa được phần khác của trang có sẵn CSS / HTML của owner. `// REVIEW-REQUIRED:`.
2. **CSS tuỳ chỉnh của khối:** `_style.customCss` (chuỗi, tối đa 5 000 ký tự). Viết kiểu Elementor: từ khoá `selector` trỏ tới khối (`selector { … }`, `selector h2 { … }`, `selector:hover { … }`); chỉ có khai báo không có `{` thì coi như `selector { … }`. Mọi rule **bắt buộc** bắt đầu bằng `selector` (sau khi thay thành `[data-eb-id="<id>"]`) – rule không có `selector` bị bỏ, để CSS của một khối không đè được cả trang. `@media` được phép, rule bên trong cũng phải có `selector`.
3. **CSS tuỳ chỉnh của trang:** prop `customCss` của `root` (tối đa 20 000 ký tự), áp cho cả trang, cùng bộ lọc (không bắt buộc `selector`, nhưng mọi selector bị đặt dưới vùng nội dung trang của builder, ví dụ `[data-eb-page] …`, không chạm header / footer / admin).
4. **Bộ lọc CSS** (`src/puck/style/custom-css.ts`, hàm thuần, chạy server khi dựng `<style>`):
   - Từ chối cả khối CSS nếu có: `<`, `</style`, `@import`, `@charset`, `@namespace`, `@font-face`, `expression(`, `javascript:`, `vbscript:`, `behavior`, `-moz-binding`, `\` (escape), chú thích chưa đóng, ngoặc `{}` không cân.
   - `url(…)`: chỉ cho đường dẫn tương đối `/api/media/file/…` (dùng lại `cleanImageUrl` của EB-05); còn lại bỏ cả khai báo.
   - Giữ nguyên thứ tự; gắn **sau** CSS `_style` của cùng khối (người viết CSS thắng).
   - `// REVIEW-REQUIRED:`. Không thêm package; nếu cần phân tích CSS thì viết bộ tách đơn giản theo `{` `}` `;` và kiểm từng phần, có unit test cho các đường vòng (escape `\3c`, chú thích chèn giữa từ khoá `@im/**/port`, chữ hoa, `url( "javascript:…")`).
5. **Widget HTML** (`HtmlWidget`, nhóm "Cơ bản", nhãn "HTML"): field `html` (textarea, tối đa 20 000 ký tự).
   - Lọc theo **danh sách cho phép** (dùng lại / mở rộng `src/lib/html/sanitize-rich-text.ts` thành bộ có cấu hình): thẻ khối và chữ thông dụng (`div`, `span`, `p`, `h2`–`h6`, `ul`, `ol`, `li`, `a`, `img`, `figure`, `figcaption`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `strong`, `em`, `br`, `hr`, `blockquote`, `code`, `pre`); thuộc tính: `class`, `id` (theo luật `cleanAnchorId`), `href` (an toàn như rich text), `src` (`img`: chỉ `/api/media/file/…`), `alt`, `title`, `width` / `height` (số).
   - **Không** `script`, `style` (thẻ và thuộc tính), `iframe`, `object`, `embed`, `form`, `input`, `svg`, `math`, mọi `on*`.
   - Lọc **trong dữ liệu trang trước `<Render>`** như rich text (`RICH_TEXT_PROPS` / `sanitizePageRichText` mở rộng cho `HtmlWidget.html`), không tự `dangerouslySetInnerHTML` chuỗi chưa lọc trong widget. `// REVIEW-REQUIRED:`.
6. **Class CSS và z-index** (tab Nâng cao, mọi khối, không cần owner): `_style.cssClasses` (danh sách tên class, mỗi tên khớp `^[a-z][a-z0-9-]{0,39}$`, tối đa 5, gắn vào lớp bọc `[data-eb-id]`); `_style.zIndex` (số nguyên -10…100, kèm `position: relative` khi có). Lọc trong `sanitizeBlockStyle`.
7. **Hiệu ứng vào khung hình** (mọi khối, không cần owner): `_style.entrance` = `none` | `fade-in` | `fade-up` | `zoom-in`, `_style.entranceDelay` = `0` | `150` | `300` | `500` (ms).
   - Một client component nhỏ duy nhất cho cả trang (gắn trong `StyledRender`) dùng `IntersectionObserver` thêm class khi khối vào khung nhìn; CSS keyframes trong stylesheet site.
   - **Không JS / `prefers-reduced-motion` → nội dung hiện bình thường**: chỉ ẩn ban đầu khi script đã chạy và đặt class lên `<html>` (ví dụ `eb-anim-ready`). Trong editor không chạy hiệu ứng.
   - Chỉ truyền dữ liệu đơn giản (không hàm) từ server sang client (lỗi EB-06b).
