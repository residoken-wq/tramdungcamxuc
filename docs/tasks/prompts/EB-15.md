## Hợp đồng chung (cả hai máy chép y hệt)

`src/puck/style/text-target.ts`:

```ts
/**
 * EB-15: marks one text element of a block so `_style.texts[key]` can style it.
 * The value is `<blockId>:<fieldKey>`, so nested blocks never pick up a parent's rule.
 */
export const TEXT_TARGET_ATTR = 'data-eb-text'

export function textTarget(blockId: string | undefined, key: string): Record<string, string> {
  return blockId ? { [TEXT_TARGET_ATTR]: `${blockId}:${key}` } : {}
}
```

- Component gắn vào **đúng phần tử chứa chữ**, ví dụ `<span {...textTarget(id, 'titleLine1')}>`.
- `key` là **tên field Puck** của chữ đó (`titleLine1`, `emotionLine`, `title`, `description`…).
- Khối con trong slot dùng `id` của chính nó.

Danh sách ô chữ của từng khối, mỗi máy một file, không sửa file của máy kia:

- `src/puck/style/text-targets/laptop.ts` (Laptop);
- `src/puck/style/text-targets/pc.ts` (PC nhà);
- `src/puck/style/text-targets/index.ts` gộp 2 file. Laptop tạo; PC nhà tạo bản giống hệt nếu chưa có:

```ts
import { LAPTOP_TEXT_TARGETS } from './laptop'
import { PC_TEXT_TARGETS } from './pc'

export type TextTargetDef = { key: string; label: string }

export const TEXT_TARGETS: Record<string, TextTargetDef[]> = {
  ...LAPTOP_TEXT_TARGETS,
  ...PC_TEXT_TARGETS,
}
```

- Máy nào chưa có file của máy kia thì tạo file đó với nội dung `export const PC_TEXT_TARGETS = {}` (hoặc `LAPTOP_…`). Planning gộp khi merge.
- `label` lấy từ `vi.ts`.

## 1. Làm (mỗi mục 1 commit)

### 1.1 Dữ liệu

Thêm vào `BlockStyle` (tuỳ chọn, không migration):

```ts
texts?: Record<string, {
  color?: string                    // token màu của designSystem
  size?: Responsive<FontSizePreset> // theo thiết bị như fontSize khối
  weight?: 400 | 600 | 700
  align?: Responsive<'left' | 'center' | 'right'>
}>
```

`sanitizeBlockStyle` nhận thêm `blockType`. Bỏ:

- key không có trong `TEXT_TARGETS[blockType]`;
- màu không có trong `designSystem.colors`;
- cỡ chữ ngoài preset khi khoá `sizes`;
- quá 20 key.

Test: dữ liệu bẩn bị bỏ, dữ liệu cũ không đổi.

### 1.2 CSS

`style-css.ts` sinh thêm cho mỗi `texts[key]`:

```css
[data-eb-text='<id>:<key>'][data-eb-text] {
  color: …;
  font-size: …;
  font-weight: …;
  text-align: …;
}
```

- Lặp attribute để thắng class Tailwind của component (cùng độ ưu tiên 0,1,0 thì thứ tự file quyết định, không chắc chắn).
- Không dùng `!important`.
- Màu dùng biến CSS của designSystem (EB-02). Cỡ chữ dùng đúng bảng preset của `fontSize` khối.
- Theo thiết bị dùng `DEVICE_MEDIA`.
- `id` và `key` qua kiểm tra như `isSafeBlockId` / `[a-zA-Z0-9]+` trước khi vào selector.
