2. **e2e `puck-templates` đỏ** vì đổi nhãn field "Tiêu đề dòng 1 (Xanh thẫm)" → "Tiêu đề dòng 1" mà chưa sửa test (lỗi 3 trong prompt). Đã sửa selector.
3. **e2e mới `puck-format` chưa từng chạy qua**:
   - chọn `<option>` theo value, trong khi Puck ghi value dạng JSON `{"value":"lg"}` → chọn theo nhãn;
   - bỏ `networkidle`;
   - bấm chọn khối thì thử lại tới khi trang đã hydrate.
     Ghi chú cho PK-02 trở đi: field `select` của Puck chọn bằng `selectOption({ label })`.
