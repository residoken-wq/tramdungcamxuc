## Nguyên nhân (đã truy tới dòng)

`src/app/(builder)/builder/[pageId]/PuckEditorClient.tsx` dòng ~683–716:

1. `<PuckDispatcherHook onReady={setPuckDispatch} />` → `onReady(dispatch)` gọi `setPuckDispatch(dispatch)`. Setter của `useState` nhận **hàm** thì coi là hàm cập nhật → React gọi `dispatch(prevState = null)` → reducer Puck đọc `null.type` → crash. (Đúng: `setPuckDispatch(() => dispatch)`.)
2. Đặt component con **bên trong** `<Puck>…</Puck>`: với Puck, có `children` nghĩa là dùng giao diện tự dựng (composition) thay giao diện mặc định → canvas/thanh khối biến mất kể cả khi hết lỗi 1.
