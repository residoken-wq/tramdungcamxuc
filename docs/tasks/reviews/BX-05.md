### Lỗi phải sửa: báo trước cho Hana (mục 3 prompt) không dùng được

Script phải chạy **trước** deploy, tức là lúc DB thật **chưa có** cột `use_default_copy_*`. QA dựng DB đủ migration trừ BX-05 (đúng trạng thái prod), chạy `scripts/report-empty-copy.ts` của nhánh:

```
cause: error: column products.use_default_copy_hero does not exist
```

`payload.find` / `findGlobal` đọc mọi cột theo config mới, nên script chết ngay khi chưa migrate.

Lệnh trong `docs/RUNBOOK.md` cũng sai 2 chỗ:

1. `-p tdcx-demo`: server thật là project **`tdcx`** (container `tdcx-app-1`).
2. `exec app node --import tsx scripts/report-empty-copy.ts`: container `app` là image runtime (Next standalone) – **không có** thư mục `scripts/` và không có `tsx`. Trước deploy nó còn là bản cũ, chưa có script.

**Cách sửa:**

1. **Script chạy được khi chưa có cột BX-05:**
   - đọc bằng `select` chỉ các ô chữ / danh sách cần kiểm (không đọc cột `useDefaultCopy*`);
   - đọc cờ `useDefaultCopy*` riêng, chỉ khi cột đã tồn tại (kiểm `information_schema.columns` qua `payload.db.drizzle`). Chưa có cột → coi là **tắt**, đúng với lúc deploy.
   - Vẫn **chỉ đọc**.
2. **RUNBOOK** – chạy bằng image `tools` (stage `builder`, có đủ mã nguồn + `pnpm`), đúng thứ tự:
   1. BX-05 merge, CI `main` xanh (đã đẩy `latest` + `tools-latest` mới);
   2. trên server:
      ```bash
      cd /opt/tdcx
      docker compose -p tdcx -f docker-compose.prod.yml --profile tools pull seed < /dev/null
      docker compose -p tdcx -f docker-compose.prod.yml --profile tools run --rm seed pnpm report:empty-copy
      ```
   3. gửi bảng cho Hana duyệt → rồi mới `./scripts/deploy.sh`.
3. **Test**: unit hoặc script test chạy `report-empty-copy` trên DB **chưa có** cột BX-05 (migrate đủ, bỏ `20261115_210000_bx05…`) → chạy xong, in bảng, mọi phần "Sẽ ẩn khi deploy (Tắt)".
