## Sửa trước khi merge (T0-01b)

1. **`.gitignore` đang bỏ qua cả `.claude/`** → skill `tdcx-brand` và các skill của Claude không được commit (trái với `docs/skills/SKILLS_UIUX_CAI_DAT.md` mục 7). Đổi thành:
   ```gitignore
   # IDE & local agent config
   .claude/*
   !.claude/skills/
   .gemini/
   .mcp.json
   ```
   rồi commit `.claude/skills/`. Giữ `.mcp.json` ngoài git (cấu hình theo máy).
2. **`.npmrc` có `legacy-peer-deps=true`**: ghi vào `docs/DECISIONS.md` vì sao cần (gói nào xung đột peer dependency với gói nào). Nếu bỏ được thì bỏ.
3. Thêm `.playwright-mcp/` vào `.gitignore` (thư mục tạm của MCP Playwright khi QA). Tạo `.prettierignore` cho `src/payload-types.ts` và `importMap.js`: Prettier đã format lại file sinh tự động, mỗi lần `pnpm dev` sinh lại sẽ tạo diff 300 dòng.
4. Push branch, mở PR vào `main`.
