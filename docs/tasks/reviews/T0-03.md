## Lỗi phải sửa (T0-03b)

**B1 – `/styleguide` lộ công khai trên production (Vercel).** Điều kiện ẩn dùng `process.env.CI`. Vercel đặt `CI=1` khi build → Next dựng sẵn trang thành tĩnh. Planning kiểm chứng: `CI=1 pnpm build` → `○ /styleguide` (static, ai cũng xem được); build không có `CI` → `ƒ /styleguide`. Sửa:
- bỏ phụ thuộc `CI`; dùng biến riêng `STYLEGUIDE_PUBLIC=true` (đặt trong `ci.yml` cho e2e, thêm vào `.env.example` với giá trị rỗng);
- `export const dynamic = 'force-dynamic'` cho trang;
- nghiệm thu: `CI=1 pnpm build` phải ra `ƒ /styleguide`; production không có biến + chưa đăng nhập → 404.

**B2 – E2E ghi đè file đang commit.** `styleguide.test.ts` chụp ảnh vào `docs/tasks/screenshots/*.png` mỗi lần chạy → repo luôn có thay đổi sau `pnpm test:e2e` (cả trên CI). Sửa: bỏ `page.screenshot` vào `docs/`; nếu cần ảnh thì ghi vào `test-results/` (đã gitignore). Ảnh nghiệm thu hiện có chuyển sang `docs/tasks/reviews/T0-03-styleguide-{375,1440}px.png`, chụp tay một lần.

**B3 – Lệch ký tự xuống dòng (CRLF/LF) trên Windows.** `src/payload-types.ts` hiện "modified" sau mỗi lần `pnpm dev` dù nội dung y hệt. Sửa: thêm `.gitattributes` (`* text=auto eol=lf`, `*.png binary`), chạy `git add --renormalize .` trong commit riêng.
