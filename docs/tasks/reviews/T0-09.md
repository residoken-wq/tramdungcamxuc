## Yêu cầu bổ sung cho phần chính (ngoài task card)

1. **Login quay về đúng editor**: chưa đăng nhập → `/admin/login?redirect=/builder/<id>`; đăng nhập xong phải về đúng `/builder/<id>`. Kiểm chứng Payload chấp nhận `redirect` ngoài `/admin`; nếu không → báo Planning, không tự viết trang login.
2. **`pageId` không hợp lệ / không tồn tại → 404**, không lộ lỗi server.
3. **Canvas đúng font và màu brand**: Puck vẽ canvas trong iframe → layout `(builder)` phải nạp cùng `next/font` (Anton, Montserrat, Playfair, subset `vietnamese`) và CSS token/Tailwind như `(site)`; biến font phải có trong iframe. Tiêu chí: ảnh chụp editor có khối Hero hiển thị Anton và "Ữ Ộ Ặ" đúng dấu trong canvas.
4. **`/builder/**` luôn `noindex`** (metadata `robots: { index: false }` ở layout builder).
5. **Lưu nháp / Xuất bản là 2 nút riêng** (override thanh công cụ của Puck), nhãn tiếng Việt, có trạng thái đang lưu / đã lưu / lỗi.
6. **Thêm `pnpm-lock.yaml` vào `.prettierignore`** (được phép sửa file này) để lockfile không bị format qua lại.
