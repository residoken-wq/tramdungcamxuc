# Quyết định kỹ thuật T1-17d: Đọc địa chỉ site lúc chạy (Runtime SITE_URL)

**Ngày:** 08/10/2026  
**Người thực hiện:** Antigravity (máy Local)  
**Phạm vi:** `src/lib/site-url.ts`, `src/lib/forms/submit.server.ts`, `src/app/(site)/layout.tsx`, `src/app/sitemap.ts`, `src/app/robots.ts`, `docker-compose.prod.yml`, `.env.example`, `docs/RUNBOOK.md`, `tests/unit/site-url.test.ts`.

---

## 1. Vấn đề

Biến môi trường `NEXT_PUBLIC_SITE_URL` bị Next.js thay thế trực tiếp vào mã nguồn lúc build (compile-time inlining). Khi image Docker được build trên CI GitHub Actions mà không có biến này, Next.js chèn cứng fallback mặc định `https://tramdungcamxuc.com`.

Hệ quả trên môi trường Docker demo (chạy tại IP/cổng riêng, vd. `http://IP-SERVER:3400`):

- Đường link tải tài nguyên miễn phí gửi qua email trỏ về domain chính thức chưa chạy.
- Metadata (`metadataBase`), thẻ OpenGraph, canonical URL, sitemap và robots trỏ sai địa chỉ.

## 2. Giải pháp

1. **Tạo helper server-only `src/lib/site-url.ts`**:
   - Hàm `getSiteUrl()` đọc từ biến môi trường runtime ở server:
     `process.env.SITE_URL` → `process.env.NEXT_PUBLIC_SITE_URL` → `https://tramdungcamxuc.com`.
   - Chuẩn hóa: nếu thiếu giao thức `http(s)://` thì thêm `https://` (vẫn giữ nguyên `http://` cho các IP local/demo); bỏ toàn bộ dấu `/` ở cuối chuỗi.
2. **Cập nhật 4 vị trí sử dụng**:
   - `src/lib/forms/submit.server.ts`: link tải tài nguyên trong email nhận `baseUrl` từ `getSiteUrl()`.
   - `src/app/(site)/layout.tsx`: `metadataBase` lấy từ `getSiteUrl()`, thêm `export const dynamic = 'force-dynamic'` để layout không bị prerender cứng lúc build.
   - `src/app/sitemap.ts`: `getBaseSiteUrl()` gọi `getSiteUrl()`.
   - `src/app/robots.ts`: giữ nguyên gọi `getBaseSiteUrl()` (đã có `force-dynamic`).
3. **Cấu hình Docker & Tài liệu triển khai**:
   - `docker-compose.prod.yml`: thêm `SITE_URL: ${SITE_URL:-}` vào service `app`.
   - `.env.example`: thêm biến `SITE_URL=` có chú thích rõ ràng.
   - `docs/RUNBOOK.md`: bổ sung `SITE_URL=http://IP-SERVER:3400` vào khối cấu hình `.env` cho bản demo.
4. **Kiểm thử**:
   - `tests/unit/site-url.test.ts`: kiểm tra đầy đủ thứ tự ưu tiên, fallback, thêm `https://`, giữ `http://`, xóa `/` cuối.
   - Các bộ test liên quan (`tests/unit/seo.test.ts`, `tests/unit/security-headers.test.ts`) tiếp tục xanh 100%.
