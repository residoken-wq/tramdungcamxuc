# EB-02 – Trang đọc màu, font, bo góc, khoảng thở từ `designSystem`

> Kế hoạch: `docs/plan/BUILDER_ELEMENTOR.md` (task EB-02) · Làm bởi: Planning · Không migration.

## 1. Cách làm

- `src/components/design/DesignSystemStyle.tsx` (server) nằm trong `<head>` của layout site `(site)` và layout trình dựng trang `(builder)`. Đọc `getDesignSystem()` và render:
  - Một `<style>` duy nhất dạng `html:root{…}`, **chỉ** gồm biến khác bộ mặc định Brand Book (`buildDesignCss`). `html:root` mạnh hơn class biến của `next/font` gắn trên `<html>`.
  - Một `<link>` Google Fonts (CSS2, `display=swap`) **chỉ** khi có vai trò đổi sang font khác font mặc định (`googleFontsHref`). Font mặc định (Anton, Montserrat, Playfair Display) vẫn là file tự host qua `next/font/local`.
- **Site dùng bộ mặc định → không có `<style>`, không có `<link>`** → trang y hệt trước EB-02.
- Biến: `--color-<token>` + `--color-<token>-rgb` (Tailwind dùng bản rgb), `--font-display` / `--font-ui` / `--font-quote` / `--font-body`, `--radius-card`, `--space-breath-{sm,md,lg}`.

## 2. Đổi trong Tailwind / CSS

| Chỗ                               | Trước                    | Sau                                                                    |
| --------------------------------- | ------------------------ | ---------------------------------------------------------------------- |
| `fontFamily.sans` (đoạn văn)      | `var(--font-ui)`         | `var(--font-body, var(--font-ui))`: vai trò "Đoạn văn" mới có tác dụng |
| `spacing.breath-*`                | `16px` / `24px` / `32px` | `var(--space-breath-*, …)`                                             |
| `borderRadius.card`               | `20px`                   | `var(--radius-card, 20px)`                                             |
| `boxShadow.soft`, `--shadow-soft` | `rgba(40, 10, 96, 0.06)` | `rgb(var(--color-deep-navy-rgb) / 0.06)`: bóng theo màu chữ chính      |

Giá trị mặc định không đổi (test `design-css.test.ts` so bộ mặc định với `styles.css`).

## 3. Font Google

- Mỗi font trong `DESIGN_FONT_OPTIONS` ghi sẵn trọng lượng có thật trong 400 / 600 / 700 và có italic hay không. Test đối chiếu `font-data.json` của `next/font`, tránh xin trọng lượng Google không có (Google trả lỗi 400).
- Vai trò "Câu trích" xin thêm italic 400 khi font có italic.
- CSP: `style-src` thêm `https://fonts.googleapis.com`, `font-src` thêm `https://fonts.gstatic.com`.
