# Quyết định kỹ thuật CM-01 – Menu admin theo việc của Hana + Ẩn mục kỹ thuật theo vai trò

> Trạng thái: Hoàn thành.  
> Nhiệm vụ: Tái cấu trúc menu quản trị Payload CMS 3 theo luồng công việc thực tế của Hana, bảo vệ mục kỹ thuật theo vai trò và áp dụng nhận diện thương hiệu nhẹ nhàng.

---

## 1. Bối cảnh & Mục tiêu

- **Vấn đề ban đầu**: Hệ thống có 35 collections và 2 globals. Nếu để mặc định, Payload hiển thị một danh sách phẳng dài hoặc gom nhóm lộn xộn, khiến Hana (người không có chuyên môn kỹ thuật) bị choáng ngợp và khó tìm thấy nội dung cần sửa hàng ngày.
- **Phân vai người dùng**:
  - `owner` (Hana / Chủ dự án): Toàn quyền truy cập, cần thấy đầy đủ các nhóm nghiệp vụ và nhóm kỹ thuật khi cần phối hợp xử lý sự cố cùng kỹ sư IT.
  - `editor` (Cộng sự / Biên tập viên): Chỉ phụ trách viết bài, đăng lời chia sẻ, cập nhật thông tin khóa học; không được và không nên thấy các bảng kỹ thuật (sự kiện thanh toán, nhật ký kiểm toán, token OTP, tài liệu riêng tư...).
- **Mục tiêu**:
  1. Tổ chức menu bên trái thành **6 nhóm nghiệp vụ rõ ràng** theo thứ tự ưu tiên làm việc của Hana.
  2. Ẩn toàn bộ 16 collections thuộc nhóm kỹ thuật khỏi menu đối với vai trò `editor` bằng `admin.hidden` (không thay đổi logic phân quyền API `access`).
  3. Bổ sung `admin.description` bằng tiếng Việt dễ hiểu, `defaultColumns` (3–5 cột có ích), `listSearchableFields` và `useAsTitle` có nghĩa cho từng collection.
  4. Đưa logo, icon thương hiệu và màu nhấn nhẹ nhàng (`deep-navy`, `accent-pink`, `bright-magenta`) vào giao diện admin, đảm bảo tương phản WCAG AA và không phá vỡ bố cục gốc của Payload.

---

## 2. Cấu trúc 6 nhóm nghiệp vụ trong Menu (`vi.cms.nav`)

Các tên nhóm được khai báo tập trung trong `src/lib/i18n/vi.ts` (khối `cms.nav`):

| STT | Tên nhóm (`vi.cms.nav`) | Key         | Danh sách Collections & Globals                                                                                                                                                                                                                                          | Vai trò hiển thị   |
| :-- | :---------------------- | :---------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------- |
| 1   | **Trang web**           | `website`   | `Pages`, `Posts`, `Testimonials`, `LegalPages`, `Navigation` (global), `SiteSettings` (global)                                                                                                                                                                           | `owner` + `editor` |
| 2   | **Sản phẩm & bán hàng** | `commerce`  | `Products`, `Services`, `Programs`, `Orders`, `DiscountCodes`                                                                                                                                                                                                            | `owner` + `editor` |
| 3   | **Khóa Habit**          | `habit`     | `CourseModules`, `Lessons`, `Techniques`, `DiagnosticQuestions`, `Workshops`                                                                                                                                                                                             | `owner` + `editor` |
| 4   | **EQ Buddy**            | `eq`        | `EqCards`                                                                                                                                                                                                                                                                | `owner` + `editor` |
| 5   | **Học viên & khách**    | `customers` | `Customers`, `Leads`, `Certificates`, `HabitPlans`                                                                                                                                                                                                                       | `owner` + `editor` |

## 3. Ẩn mục kỹ thuật theo vai trò (`admin.hidden`)

- **Ranh giới an toàn**:
  - Quyền API (`access`) được giữ nguyên vẹn để các luồng backend, webhook và tác vụ nội bộ hoạt động bình thường.
  - Sử dụng thuộc tính `admin.hidden` của Payload 3 để kiểm soát hiển thị trên thanh điều hướng.
- **Helper `isHiddenFromEditor` (`src/lib/auth/access.ts`)**:
  ```ts
  // REVIEW-REQUIRED: Controls admin navigation visibility for non-technical editors.
  // API access rules remain untouched; this only hides system collections from the admin nav.
  export const isHiddenFromEditor = ({
    user,
  }: {
    user?: ClientUser | Record<string, unknown> | null
  }): boolean => {
    if (!user) return true
    return (user as { role?: string }).role !== 'owner'
  }
  ```
  - Khi user là `owner` $\rightarrow$ trả về `false` (hiển thị đầy đủ 6 nhóm).
  - Khi user là `editor` $\rightarrow$ trả về `true` (ẩn hoàn toàn 16 collections nhóm Hệ thống).

## 4. Mô tả, tiêu đề và cột mặc định cho Collections

- Mỗi collection đều có:
  - `admin.description`: Câu mô tả tiếng Việt 1 dòng giải thích công dụng thực tế cho Hana.
  - `admin.useAsTitle`: Trường hiển thị tên tài liệu trực quan (thay vì ID số gây khó hiểu).
  - `admin.defaultColumns`: 3 đến 5 cột quan trọng nhất khi xem danh sách.
  - `admin.listSearchableFields`: Các trường cho phép tìm kiếm nhanh.

## 5. Nhận diện thương hiệu Admin (Brand Graphics & Styling)

- **Logo và Icon** (`src/components/admin/brand/`):
  - `AdminLogo`: Biểu tượng nhịp tim cảm xúc (`HeartLine`) màu `accent-pink` trên nền `deep-navy`, kèm tên thương hiệu "TRẠM DỪNG CẢM XÚC" (Montserrat Bold) và phụ đề "Hệ thống quản trị" (bright-magenta).
  - `AdminIcon`: Biểu tượng hình vuông bo góc nhỏ gọn cho menu thu gọn và favicon tab trình duyệt.
  - Đăng ký qua `admin.components.graphics.Logo` và `Icon` trong `src/payload.config.ts`, cập nhật qua `pnpm generate:importmap`.
- **Hậu tố tiêu đề trang**:
  - `admin.meta.titleSuffix = ' – Trạm Dừng Cảm Xúc'`.
- **Phong cách CSS nhẹ nhàng (`src/app/(payload)/custom.scss`)**:
  - Khai báo biến màu theo Brand Book 2026: `--brand-deep-navy: #280a60`, `--brand-accent-pink: #ef3b83`, `--brand-bright-magenta: #bc039e`.
  - Hỗ trợ chế độ sáng/tối với độ tương phản WCAG AA.
  - Điểm nhấn viền trái thanh điều hướng đang chọn (`border-left: 2px solid var(--brand-accent-pink)`), focus-visible ring trang nhã.
  - Giữ nguyên 100% cấu trúc và bố cục mặc định của Payload CMS.
