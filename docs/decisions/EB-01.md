# EB-01 – Global `designSystem`: bảng màu, font, công tắc khoá / mở brand

> Kế hoạch: `docs/plan/BUILDER_ELEMENTOR.md` (mục 3, 6) · Prompt: `docs/tasks/prompts/EB-01.md` · Làm bởi: Planning.
> Migration: `src/migrations/20261031_080633_eb01_design_system.ts`.

## 1. Phạm vi

Chỉ dữ liệu, hàm đọc và màn admin. **Trang công khai không đổi**: CSS, Tailwind, `next/font` giữ nguyên. Nối biến CSS vào global này là EB-02.

## 2. Field (`src/globals/DesignSystem.ts`)

| Field                                 | Kiểu                             | Mặc định                                           | Luật                                                                                                          |
| ------------------------------------- | -------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `colors[]`                            | { token, label, hex }, 1–16 dòng | 8 màu Brand Book (`src/lib/brand/tokens.ts`)       | `token` chữ thường-số-gạch nối, duy nhất. `hex` dạng `#RRGGBB`. 8 token lõi bắt buộc có (không xoá / đổi tên) |
| `fonts.{heading,ui,quote,body}`       | text + dropdown                  | Anton / Montserrat / Playfair Display / Montserrat | Phải nằm trong `DESIGN_FONT_OPTIONS`                                                                          |
| `radiusCard`                          | số 0–48                          | 20                                                 |                                                                                                               |
| `spacing.{sm,md,lg}`                  | số 0–96                          | 16 / 24 / 32                                       |                                                                                                               |
| `lock.{colors,fonts,sizes,customCss}` | `locked` \| `open`               | `locked`                                           | Mặc định sản phẩm cho site mới: khoá (chốt 31/10)                                                             |
| `lock.contrastCheck`                  | checkbox                         | bật                                                |                                                                                                               |

- **Token lõi giữ tên:** code đang dùng class Tailwind theo tên (`text-deep-navy`…). Đổi tên sẽ làm mất màu ở khắp nơi. Khách khác đổi HEX của token lõi để có màu riêng. Đổi sang tên theo vai trò (`primary`, `accent`…) là việc riêng → BACKLOG.
- **Font lưu dạng text, không phải enum Postgres:** thêm font vào danh sách không cần migration. Danh sách gồm 30 font Google có subset `vietnamese`; test đọc `font-data.json` của `next/font` để kiểm. `font-data.json` không có loại font, nên `category` ghi tay.
- **Global trống** (chưa lưu lần nào): `getDesignSystem()` trả bộ mặc định Brand Book. Đọc lỗi cũng trả mặc định, không làm hỏng trang.

## 3. Quyền

- `read`: công khai. EB-02 cần đọc để render; global chỉ chứa token và công tắc, không có dữ liệu cá nhân / thanh toán.
- `update`: chỉ `owner`. `editor` xem được, không lưu được.
- Cả hai chỗ đánh `REVIEW-REQUIRED`.

## 4. Màn admin

- Ô màu (`ColorField`): ô chọn màu của trình duyệt + ô HEX đồng bộ + ô mẫu + tỷ lệ tương phản với trắng và `warm-ivory` (chỉ hiển thị, không chặn).
- Dòng màu thu gọn hiện "token – tên" kèm ô mẫu (`ColorRowLabel`).
- Font: dropdown (`FontSelectField`).
- Có công tắc **Mở** → hiện dòng "Đang mở – trang có thể lệch bộ nhận diện" (`LockWarning`).
- Không thêm package.

## 5. Hàm

- `src/lib/design/design-system.ts` (client-safe): `cleanDesignSystem`, `isOpen`, `hexToRgbTriplet`, `contrastRatio` (WCAG 2.x), `colorListProblem`, `DEFAULT_DESIGN_SYSTEM`.
- `src/lib/design/design-system.server.ts`: `getDesignSystem(payload?)`, cache theo request (`react` `cache`).
- `src/lib/design/fonts.ts`: `DESIGN_FONT_OPTIONS`, `DEFAULT_FONTS`.

## 6. Mở cho site Trạm

Theo quyết định 31/10, Trạm Dừng Cảm Xúc **mở**. Việc này không ghi vào migration / seed, vì cùng code chạy cho khách khác. Sau khi deploy, `owner` vào **Trang web → Thiết kế & thương hiệu** và chuyển các công tắc sang **Mở**. Trước EB-04 việc mở chưa có tác dụng gì.

## 7. Việc để lại

- **EB-02**:
  - Sinh `--color-*` / `--color-*-rgb`, font, bo góc, khoảng cách từ `getDesignSystem()`.
  - Tải Google Fonts lúc chạy (`display=swap`, subset `vietnamese`), mở CSP cho `fonts.googleapis.com` / `fonts.gstatic.com`.
  - Trang cũ phải giữ y hệt khi dùng bộ mặc định.
  - Bảng màu trong `ColorField` đang so tương phản với `warm-ivory` lấy từ code. Khi EB-02 xong thì lấy từ bảng màu đã lưu.
- **EB-04:** các control khoá / mở trong trình dựng trang đọc `isOpen()`.
- **BACKLOG:** token theo vai trò thay cho tên màu Trạm.
